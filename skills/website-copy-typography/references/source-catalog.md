## Selection rules

Use W3C and current official product/legal documentation for conformance or facts. Use GOV.UK and Impeccable as pragmatic UX/editorial methods. Use open skills as prompts for review, not truth sources. Use Google Fonts only after checking the specific family’s characters, variable axes, and license.
