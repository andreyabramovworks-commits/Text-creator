# Text Creator

Agent Skill для исследования, написания и проверки текстов сайтов на русском и английском, со структурой страниц и типографикой.

Начните с [SKILL.md](skills/website-copy-typography/SKILL.md). Навык использует бриф и проверяемые исходные данные для текста, затем подбирает подходящую структуру и проверяет результат в реальном макете. [Рецепты страниц](skills/website-copy-typography/references/page-recipes.md), [модели блоков](skills/website-copy-typography/references/block-patterns.md), [типографика](skills/website-copy-typography/references/typography.md), [Copy QA](skills/website-copy-typography/references/copy-qa.md) и [каталог источников](skills/website-copy-typography/references/source-catalog.md) читаются по задаче.

## Установка в Codex

Скопируйте каталог `skills/website-copy-typography` в `$CODEX_HOME/skills/website-copy-typography` или `~/.codex/skills/website-copy-typography`, если `CODEX_HOME` не задан. Перезапустите Codex. Явный вызов: `$website-copy-typography`.

## Примеры запросов

- «Используй $website-copy-typography: из этих интервью и описания продукта собери структуру лендинга и напиши русский и английский текст. Отметь неподтверждённые обещания».
- «Перепиши тарифную страницу: проверь аудиторию каждого плана, включённые лимиты, формулировки CTA и типографику на мобильном».
- «Проверь форму заявки: подписи полей, ошибки, подтверждение отправки, доступность и длинные строки».

## Исследовательская основа

Источники в каталоге разделены на официальные правила, открытые skills, инструменты и шрифты. Они дают методы и примеры; факты о конкретном бизнесе должны приходить из брифа и проверяемых материалов. В пакете нет скопированных чужих текстов или шрифтов. Для отзывов и показателей указан отдельный порядок проверки, для шрифтов — проверка лицензии каждой семьи.

Это локальная версия для обсуждения. Авторские файлы пакета распространяются по [MIT](LICENSE); условия сторонних источников остаются у их правообладателей.
